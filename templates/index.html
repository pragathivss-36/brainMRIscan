Architecture

About the AI Model

Technical details of the deep learning architecture behind PM (1).keras.

Model Architecture

Sequential 4-Block Convolutional Neural Network (CNN) engineered specifically for spatial feature extraction in brain MRI slices.

Input Preprocessing

Accepts 224 × 224 × 3 RGB image tensors with built-in feature rescaling (1/255) for numerical stability.

Parameter Count

1,265,486 Total Parameters with 421,828 trainable weights optimized for deep neuro-feature detection.

4 Output Classes

Calculates categorical Softmax probability distribution across: Mild Demented, Moderate Demented, Non Demented, and Very Mild Demented.

CNN Pipeline Overview

01

Rescaling Layer

Normalizes raw RGB 0-255 pixels to [0, 1] range.

02

Conv2D + MaxPool2D

4 feature extraction blocks with 32, 64, 128, and 256 filters.

03

Global Average Pooling

Reduces spatial dimensions while preserving key spatial activations.

04

Dense & Softmax Output

128-unit FC layer + Dropout (regularization) + 4-unit Softmax class classifier.
